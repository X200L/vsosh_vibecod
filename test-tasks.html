Задача 7 Алгоритмическая

Робот-доставщик

Робот находится в точке (0, 0). Ему передаётся последовательность команд: U — вверх, D — вниз, L — влево, R — вправо.

Необходимо определить минимальное количество шагов, которое потребуется роботу, чтобы вернуться в начало координат после выполнения всех команд.

Пример
Ввод: UURRRD После команд робот в точке (3, 1). |3| + |1| = 4 Вывод: 4
Ограничения
Строка команд длиной до 10⁶ символов.

Задача 10 Сложная

Утечка nonce в ECDSA

В криптографической системе ECDSA, работающей на эллиптической кривой secp256k1, была допущена критическая ошибка: для двух различных сообщений использовался один и тот же одноразовый параметр (nonce) k.

Это позволяет восстановить секретный ключ подписи. Вам даны параметры двух подписей и порядок группы. Требуется восстановить приватный ключ d.

n = 115792089237316195423570985008687907852837564279074904382605163141518161494337 r = 64815329020249867864849938248946398274839967837590476665552683842330605994785 z1 = 21537068444347613717626221621... (хеш первого сообщения) z2 = 98765432109876543210987654321... (хеш второго сообщения) s1 = 55555555555555555555555555555... (подпись 1) s2 = 44444444444444444444444444444... (подпись 2)

Формула восстановления: k = (z1 - z2) * modinv(s1 - s2, n) mod n, затем d = (s1*k - z1) * modinv(r, n) mod n.

Формат ответа
Одно большое целое число — значение приватного ключа d.
