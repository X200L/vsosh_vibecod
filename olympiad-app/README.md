# Система управления олимпиадами

Это веб-приложение для управления олимпиадами с двумя типами пользователей: участниками и организаторами. Приложение включает публичную страницу с информацией об олимпиаде, страницу с заданиями пригласительного тура, а также личные кабинеты для участников и организаторов.

## Технологии

- **Backend**: Flask (Python)
- **Frontend**: HTML, CSS, JavaScript
- **Стилизация**: Custom CSS с современным дизайном

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python3 app.py
```

3. Откройте браузер и перейдите по адресу: `http://localhost:5000`

## Страницы приложения

### Публичные страницы
- **Главная страница** (`/`) - Информация об олимпиаде, график проведения, этапы
- **Пригласительный тур** (`/test-tasks`) - Задания для проверки навыков программирования

### Авторизованные страницы
- **Регистрация** (`/register`) - Создание нового аккаунта (участник или организатор)
- **Вход в систему** (`/login`) - Страница авторизации
- **Личный кабинет участника** (`/participant/dashboard`) - Просмотр олимпиад и результатов
- **Личный кабинет организатора** (`/organizer/dashboard`) - Управление олимпиадами и участниками

## Функционал

### Публичные страницы
- Информация о ВсОШ по вайбкодингу
- График проведения этапов олимпиады
- Описание этапов олимпиады
- 10 заданий пригласительного тура с разной сложностью
- Прогресс выполнения заданий (сохраняется в localStorage)
- Регистрация новых пользователей (участники и организаторы)

### Для участников
- Просмотр доступных олимпиад
- Регистрация на олимпиады
- Просмотр своих результатов
- Статистика участия

### Для организаторов
- Создание новых олимпиад
- Управление существующими олимпиадами
- Просмотр списка участников
- Управление результатами
- Экспорт отчетов

## Регистрация

Для регистрации нового аккаунта:
1. Перейдите на страницу регистрации (`/register`)
2. Заполните форму:
   - Имя пользователя
   - Полное имя
   - Email
   - Роль (участник или организатор)
   - Пароль (минимум 6 символов)
   - Подтверждение пароля
3. Нажмите "Зарегистрироваться"
4. После успешной регистрации вы будете перенаправлены на страницу входа

## Безопасность

⚠️ **Важно**: В текущей версии используется простая система аутентификации с хранением паролей в памяти. Для продакшн-использования необходимо:
- Использовать базу данных (PostgreSQL, MySQL)
- Хешировать пароли (bcrypt, argon2)
- Использовать HTTPS
- Добавить CSRF защиту
- Реализовать валидацию форм на сервере
- Добавить подтверждение email
- Реализовать восстановление пароля

## Разработка

Для добавления новых функций:

1. Добавьте новый маршрут в `app.py`
2. Создайте соответствующий HTML шаблон в `templates/`
3. Добавьте стили в `static/css/style.css` при необходимости
4. Добавьте JavaScript функционал в `static/js/script.js` при необходимости
