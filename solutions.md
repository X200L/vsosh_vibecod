## Задача 5. Умный склад

**Ответ: 3**

### Решение:

Алгоритм: отсортировать коробки по весу в порядке возрастания, добавлять коробки пока не превышена грузоподъёмность.

```python
n, k = 5, 10
weights = [2, 3, 5, 6, 4]

weights.sort()  # [2, 3, 4, 5, 6]

count = 0
total = 0
for w in weights:
    if total + w <= k:
        total += w
        count += 1
    else:
        break

# total = 2 + 3 + 4 = 9 (≤ 10) ✓
# 9 + 5 = 14 (> 10) ✗
# Ответ: 3
```

x, y = 0, 0
for cmd in commands:
    if cmd == 'U':
        y += 1
    elif cmd == 'D':
        y -= 1

## Задача 10. Сломанный поиск

**Ответ: 4**

### Исправленный код:

```python
def count_occurrences(arr, target):
    left = 0
    right = len(arr) - 1

    # Находим ПЕРВОЕ вхождение
    while left < right:
        mid = (left + right) // 2
        if arr[mid] < target:
            left = mid + 1
        else:
            right = mid

    first = left

    left = 0
    right = len(arr) - 1

    # Находим ПОСЛЕДНЕЕ вхождение
    while left < right:
        mid = (left + right + 1) // 2  # ИСПРАВЛЕНИЕ: добавляем +1
        if arr[mid] <= target:
            left = mid
        else:
            right = mid - 1

    last = left

    return last - first + 1

# Для [1, 2, 2, 2, 3, 4, 4, 5, 5, 5, 5, 6, 7] и target=5
# first = 7, last = 10
# Ответ: 10 - 7 + 1 = 4
```

**Ошибка:** В цикле поиска последнего вхождения нужно использовать `(left + right + 1) // 2` вместо `(left + right) // 2`, чтобы избежать бесконечного цикла.
